# LiveCameraLinks 要件定義書 v0.2.0

## 改訂方針
本版は v0.1.4 をベースにした差分更新版です。

## 主な更新
- 正式名称を **LiveCameraLinks（ライブカメラリンクス）** に統一
- コンセプトを「現地は？ 天気は？ 道は？」に統一
- GitHub を正本（Single Source of Truth）とする運用を追加
- Production Baseline を採用
- Place（目的地）中心の設計方針を追加
- Camera Index によるデータ管理方針を追加

- 2026-10-03 v0.1.4 初版
