# 05_PLACE_INDEX

**Project:** LiveCameraLinks  
**Version:** Release 0.2.2  
**Last Update:** 2026-10-04

---

# 1. 目的

Place Index は、LiveCameraLinks に登録する「場所（Place）」を一元管理するための仕様である。

Camera（ライブカメラ）を単独で管理するのではなく、

- 目的地
- 道路
- 駅
- 観光地
- 温泉
- 繁華街

などを Place として管理し、複数のライブカメラを関連付ける。

---

# 2. Placeとは

Placeとは、

ユーザーが検索・閲覧する対象となる場所を表す。

例

- 箱根
- 河口湖
- 東京駅
- 京都駅
- 白川郷
- 富士山
- 草津温泉

Placeには複数のライブカメラを登録できる。

# 4. Place情報

各Placeは次の情報を保持する。

- Place ID
- Place名
- 都道府県
- 市区町村
- Place種別
- 緯度
- 経度
- 説明
- タグ
- OpenStreetMap

---

# 5. Cameraとの関係

1つのPlaceに複数のCameraを登録できる。

例

Place

箱根

↓

Camera

・大観山ライブカメラ

・芦ノ湖ライブカメラ

・箱根峠ライブカメラ

・湯本駅ライブカメラ

・国道1号ライブカメラ

---

# 6. Routeとの関係

RouteはPlace同士を結ぶ。

例

東京

↓

箱根

↓

熱海

Routeページでは

- 出発地
- 経由地
- 目的地

を管理する。

# 7. 都道府県構造

```
 └─ 東京タワー

神奈川県
 ├─ 箱根

 ├─ 鎌倉
 └─ 江の島
```

---

# 12. 開発方針

LiveCameraLinksでは

Cameraを中心とするサイトではなく、

Placeを中心とした

全国ライブカメラプラットフォーム

として開発を進める。

CameraはPlaceを構成する要素として管理し、

Route・Weather・Map・OpenStreetMapと連携する。
