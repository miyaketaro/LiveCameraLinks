# 1. 目的

Camera Index は、LiveCameraLinks に収録する全国ライブカメラを一元管理するための管理台帳である。

目的は次のとおり。

- 全国ライブカメラの収録状況を管理する
- カメラの重複登録を防止する
- 探索状況を管理する
- 今後の追加対象を管理する
- Place Index と連携する

---

# 2. 基本方針

LiveCameraLinks は

**「現地は？ 天気は？ 道は？」**

をコンセプトとする全国ライブカメラプラットフォームである。

道路状況・観光地・駅・繁華街などを統合し、

利用者が

- 今どんな状況か
- 目的地はどうか
- 道路は混んでいるか

を確認できることを目的とする。

# 4. 収録ルール

## LIVE映像

最優先で収録する。

---

## 静止画

次の条件を満たす場合のみ掲載。

- 定期更新
- 更新間隔が明記されている

---

## 録画動画

掲載対象外。

---

## 配信元

優先順位

1. 公式サイト
2. 自治体
3. 国土交通省
4. 観光協会
5. 公式YouTube

---

## 他社ライブカメラサイト

以下は候補探索のみ利用する。

- ライブカメラDB
- LiveAtlas
- livecam.asia
- Fujiyama.TV
- HIR-NET
- とまり木

カードデータは転用しない。
